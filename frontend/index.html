Platform Integration

To use the Meeting Assistant with your favorite video conferencing platform, you'll need to route the audio to the app using a virtual audio cable.

Setup Instructions:

  1. Install a virtual audio cable: We recommend VB-CABLE for Windows or BlackHole for macOS.
  2. Set the virtual cable as your system's output: In your system's sound settings, select the virtual audio cable as the default output device.
  3. Set the virtual cable as your meeting app's speaker: In your video conferencing app (Zoom, Teams, etc.), go to the audio settings and select the virtual audio cable as the speaker.
  4. Start the Meeting Assistant: Click the "Start/Stop Recording" button above to begin receiving audio.
