This commit introduces the initial version of the Meeting Assistant application.

The application provides real-time audio transcription, AI-powered contextual understanding, and a searchable archive of meeting notes. It is designed to be an invisible companion during meetings, providing instant answers and insights.

Key Features:
- Real-time audio transcription using Google Cloud Speech-to-Text.
- AI-powered analysis of transcripts with OpenAI's GPT-4.
- Searchable meeting notes stored on the filesystem.
- Guidance for integration with popular video conferencing platforms.
- Customizable knowledge base for company-specific terms.
- Multilingual support for transcription and analysis.
